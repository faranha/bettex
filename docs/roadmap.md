# Engineering roadmap and evidence gates

This is an engineering readiness plan, not a change to the approved public
product roadmap, blockchain, tokenomics or alpha agent hierarchy.

1. **Repository readiness:** English technical documentation, reproducible
   installation/checks, development-only simulation, private GitHub access and
   coordinated synchronization with real-remote evidence.
2. **Alpha verification:** maintain account/wallet isolation, deterministic
   policies, immutable evidence, local-contract checks and reconciliation.
   Preserve the existing treasury control and prediction specialist structure.
3. **Resolve integration blockers:** validated Allora topics/horizons and event
   model, calibration, costs/depth/exposure evidence, explicit paper mandates and
   policy publication/approval/activation.
4. **Public test-network evidence:** reviewed deployments, funding with test
   assets, immutable contract relationships, wallet/network checks and a
   reproducible end-to-end test journey. Local EVM results do not satisfy this gate.
5. **Independent security/legal review:** production custody/signing, operational
   authority, recovery, external accounting, provider approvals and rights.
   Existing architecture reviews and tests are not independent financial audits.
6. **Production decision:** explicit authorization, operational controls,
   deployment and funding remain separate from Git synchronization and grant
   review. No automatic merge into the production branch is added.

Do not infer dates, commitments, traction, funding, partnerships or production
performance from this ordering.
