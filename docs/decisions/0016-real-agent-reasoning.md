# Real language-model reasoning, separate from financial controls

## Context and decision

The creator requires actual AI in the agents, not exclusively scripted services. Existing Allora inferences are real external model observations; operational assessment and coordination were rule-based. Those assessments must not be relabelled as generative reasoning.

The agents context now owns an inference port, a real OpenAI adapter, and persisted reasoning reports. The AI Center generates analysis on explicit request for the selected agent and language using its latest captured operational evidence. No personal account, vault, secret or wallet data is supplied. The model interprets observations, uncertainties and research next steps; source evidence is data, not instructions.

Reports retain provider/model response provenance, the original source run, evidence snapshots, language and generation time. Prior model reports remain distinct from deterministic operational runs. Provider failure or invalid output produces an error, never a synthetic substitute. Model citations are validated against the captured evidence.

## Boundaries and cost controls

No financial execution, signing, policy mutation or wallet port is injected. Model analysis does not grant authorization or calculate distributable money. Existing independent controls remain authoritative. Source observations do not establish calibrated event probabilities or profitable advantage.

Inference is development-only, explicitly triggered, with origin/content-type validation, one in-flight call and per-IP cooldown. Reading history, loading the page and polling existing services do not trigger paid inference. The SDK uses bounded timeout, token budget and limited backoff retries. Automatic scheduling, autonomous model collaboration, calibrated event models and financial execution remain separate work, not implemented by this decision.
