# Technical grant-review readiness

## Reviewable engineering work

The repository contains actual React/TypeScript/Express implementation,
OpenAPI-generated contracts, PostgreSQL domain persistence, a Solidity
test-contract library, native test-account and encrypted-wallet code,
deterministic risk controls, alpha hierarchy, isolated paper/simulation
infrastructure, treasury controls and reconciliation/audit evidence.

The [architecture](architecture.md), [agents](agents.md),
[integrations](integrations.md) and [simulation](simulation.md) describe what
those components actually prove and what remains blocked. Existing architectural
and security reports are internal engineering assessments, not external audits.

## Evidence needed before submission

- Private repository URL and reviewer access granted by the owner.
- Verified GitHub development-branch push and successful GitHub Actions run.
- Clean-clone installation/startup/build evidence with the documented toolchain.
- Tests and scenario evidence identified by environment, never presented as
  realized returns.
- License and asset provenance decision: package metadata alone is insufficient
  to grant redistribution rights to uploaded/research material.
- Independent answers to the unresolved model/provider/public-testnet gates.
- Grant-specific network/ecosystem eligibility checked against the program's
  current rules. No grant application is described as a partnership.

## Current disposition

Suitable for **engineering review with explicit limitations**, not a claim of
production readiness. GitHub activation/reviewer access and a GitHub CI run are
external dependencies. Public-testnet end-to-end execution, real-provider
trading, independent security audit and production authorization remain
unproven or pending.

No traction, funding, grants, institutional relationships, real financial
performance or audits are invented. The approved economics and blockchain
direction are not changed by repository preparation.
