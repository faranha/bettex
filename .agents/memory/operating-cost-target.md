name: Custo mensal de operação
description: Estimativa agregada de custo definida pelo criador para estudar sustentabilidade.
---

O criador estima “$50 a $75 mil por mês pra operar”, considerando salários, marketing, custos operacionais e “tokens de ANA”; pediu US$ 50 mil como cenário equilibrado. É um alvo agregado, sem distribuição aprovada entre rubricas ou salários individuais.

**Why:** O criador pediu projetar quanto o aplicativo precisa movimentar para sustentar esse custo mensal.

**How to apply:** Usar US$ 50 mil como referência central de sustentabilidade e distinguir a faixa de custo de qualquer captação mencionada. Não tratar capital captado para a tesouraria como receita operacional de tarifas.
