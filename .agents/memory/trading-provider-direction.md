O criador definiu: apostas esportivas na Polymarket, meme coins pela Robinhood ou pela FOMO e predictions pela Polymarket. O protótipo é a base do futuro aplicativo, não uma apresentação descartável; há autorização para usar banco de dados e estudar as APIs para torná-lo realista.

**Why:** O criador pediu ler a documentação das plataformas antes de modelar a operação e afirmou que a prototipação será transformada no aplicativo.

**How to apply:** Modelar esportes como mercados Polymarket, não assumir surebet entre casas. Não inferir que toda meme coin pode ser negociada na Robinhood ou que um serviço não oficial é API da FOMO. A autorização para banco/prototipação não autoriza trades reais. Confirmar qual FOMO se pretende usar quando a identidade não estiver definida.
