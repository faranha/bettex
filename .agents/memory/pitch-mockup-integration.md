---
name: Integração de mockup do Pitch
description: Direção do criador para integrar o redesign aprovado diretamente no código do Pitch.
---

Quando o criador aprovar um mockup do Pitch para integração, implemente-o diretamente no site em Build. Não abra o Designer nem mude para Design sem pedido explícito.

**Why:** O criador corrigiu que não havia pedido para abrir o Designer nem entrar no modo Design durante esta integração.

**How to apply:** Trate a aprovação do mockup como autorização para integrar no código existente; não altere o modo de trabalho por conta própria.
